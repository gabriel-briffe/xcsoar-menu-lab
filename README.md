# XCSoar menu lab

Interactive mock of a touch-first XCSoar configuration menu.

**Live page** (after the first Pages deploy):
https://gabriel-briffe.github.io/xcsoar-menu-lab/

## Use

The grey block is the simulated device. **Reorganize** opens the tree editor.
Import/export a menu as JSON from the tree toolbar.

## Deploy

Every push to `main` runs `.github/workflows/pages.yml` and publishes this repo to GitHub Pages.

First time only: **Settings → Pages → Source → GitHub Actions**.
